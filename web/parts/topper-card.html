Pencil & stylus toppers

Fit

A removable decoration for the back end. Measure where it will sit; stylus models and markers do not share one diameter. This is not an airtight marker lid or a charging adapter.

Socket shape & fit

For hex pencils measure across two flat sides. Round sockets use the diameter; oval sockets need both axes. Measure the exact place where the topper will sit. Irregular or asymmetric styluses need a custom shape.

Start with a plain socket fit test. More allowance widens the socket; less makes it tighter. The allowance changes the full opening width, not each side. The tight and loose buttons change it by 0.02 mm. Your settings and draft are kept in this browser when storage is available.

Artwork

Uses the same Meshy API key as Keycaps and Models. Meshy generates the decoration; TinyMaker builds the measured socket and checks the attachment. Generating uses Meshy credits. Artwork and the finished topper are saved to Library. Recover resumes an existing paid task without creating another. Inspect the result and test your socket fit before printing.
